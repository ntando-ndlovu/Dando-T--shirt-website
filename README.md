# Dando-T--shirt-website
T-shirt website developed for the Dando clothing brand 
## Project Overview
Dando is a T-shirt website that showcases stylish and affordable T-shirts and provides information about the brand.

## Website Goals and Objectives
The goal is to create a simple, attractive and user-friendly website where customers can view products and contact the business.

## Key Features and Functionality
- Home page
- About page
- Products page
- Contact page
- Product images and descriptions
- Easy navigation
